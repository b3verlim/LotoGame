 LotoGame

Приложение «Русское лото», разработанное на языке C# с использованием WinForms.
Проект реализует игровую логику, графический интерфейс и покрытие тестами.


 Описание проекта

Программа моделирует игру «Русское лото»:

* генерируются бочонки с числами от 1 до 90
* создаются карточки игроков
* происходит розыгрыш чисел
* определяется победитель


 Структура проекта

LotoGame
│
├── LotoGame            # основной проект
│   ├── BarrelBag.cs    # мешок с бочонками
│   ├── Player.cs       # логика игрока
│   ├── GameManager.cs  # управление игрой
│   ├── Forms           # формы (интерфейс)
│
├── LotoGame.Tests      # тестовый проект
│   └── Test1.cs        # unit-тесты
│
└── LotoGame.sln        # файл решения


 Основные классы

 `BarrelBag`

Отвечает за:

* хранение чисел от 1 до 90
* случайную выдачу чисел
* исключение повторений



 `Player`

Отвечает за:

* создание карточки 3×9
* отметку чисел
* проверку победы


 `GameManager`

Отвечает за:

* создание игроков
* управление игрой
* хранение выпавших чисел
* определение победителей



 Интерфейс

Реализован с помощью WinForms:

* `MainMenuForm` — главное меню
* `PlayersForm` — выбор количества игроков
* `GameForm` — игровой процесс
* `WinnerForm` — отображение победителя



 Тестирование

В проекте используется **MSTest**.

Проверяются:

* корректность работы мешка (`BarrelBag`)
* создание карточек
* отметка чисел
* определение победителя
* работа `GameManager`

Запуск тестов:

Тест → Обозреватель тестов → Выполнить все
